# Booklat audit

Date: 2026-10-09. Mode: after, selected by the user.

## Scope and implementation status

The folder already contains the application described in `booklat-oneshot.md`: configuration, incremental alignment, scoring, in-memory microphone processing, local API, CSV persistence, setup scripts, passages, and a single-page interface. It also contains an optional Vosk streaming engine and debugger documented in README.md. These existing additions were preserved.

No application source was changed. This report records fixes for approval under antislop's after mode. It is not a release approval.

The visual direction comes from section B10 of the project brief: warm paper surfaces, teal actions, system fonts, large passage text, and separate setup, reading, and results screens. Audit interpretation: teacher-operated reading tool, ENERGY 1 / RHYTHM 1 / MOTION 1. No new assets or design direction were created.

## Findings requiring approval

1. **HIGH, R-25: Small amber status text fails contrast.** In `web/index.html:9`, `.loading` and `.instructional` use `#a16207` on `#fef3c7`. The supplied contrast checker measures 4.42:1, below the 4.5:1 requirement for these small labels. Darken the text token enough to meet AA; retain the specified amber status meaning.

2. **HIGH, R-27: Previous scores remain visible while a new score loads or fails.** `resultsScreen()` at `web/index.html:225` reveals reused result tiles before awaiting the request. `updateScore()` at line 231 shows an error without clearing or marking the old values as stale. Another learner can therefore see the preceding learner's accuracy if scoring fails. Clear result values for a new session and show an explicit pending/unavailable state during scoring. A Node harness executing the actual `updateScore()` function confirmed that a rejected request leaves a seeded 97.0% displayed.

3. **HIGH, R-27: Recent readings retains an old error after successful recovery.** At `web/index.html:126`, `recent()` replaces the empty-state text on failure but never restores it after success. A later successful empty response still displays the previous error; a failed refresh can also leave the previous table visible. Reset empty-state text on success and distinguish loading, empty, and failed states. A Node harness executing the actual function confirmed an error followed by `[]` retains the error text.

4. **HIGH, R-32: Closing the word editor does not restore keyboard focus.** Enter or Space on a passage word focuses the editor's first button at `web/index.html:282`. Escape calls `closeEditor()` at line 152, which hides the focused editor and forgets the selected word. Restore focus to the triggering word when closing with Escape. This finding is based on source inspection; browser focus behavior was not exercised.

5. **HIGH, R-02: Interface strings contain prohibited em dashes.** Occurrences appear at `web/index.html:27`, `:193`, `:213`, and `:252`. Replace the latency placeholder with `n/a` and use a period or parentheses in diagnostic copy. The original brief also specifies the latency placeholder; retain it only if the user explicitly overrides R-02.

## Setup after dependencies are available

The project's documented setup requires `uv` and internet for dependencies and speech models:

```sh
./scripts/setup.sh
./run.sh
```

Then open `http://localhost:8000`. Select Whisper for that setup; optional Vosk requires `./scripts/setup_vosk.sh`. The full suite runs with `.venv/bin/python -m pytest -q` once dependencies are installed.
